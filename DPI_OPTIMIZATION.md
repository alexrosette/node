# DPI-Resistant Оптимизации для Remnawave Node

## Обзор

Эта система добавляет мощные возможности для обхода Deep Packet Inspection (DPI) систем, используя современные техники маскировки трафика и оптимизации протоколов.

## Возможности

### 🚀 Поддерживаемые транспорты для обхода DPI:

1. **XHTTP** (🔥 МАКСИМАЛЬНАЯ МАСКИРОВКА) - Транспорт с максимальной защитой от DPI
   - Маскировка под обычные HTTP запросы
   - Генерация мусорного трафика (30% по умолчанию)
   - Изменение сигнатур пакетов
   - Реалистичные HTTP заголовки
   - **Рекомендуется для максимальной защиты!**

2. **Reality** (рекомендуется) - Самый эффективный протокол для обхода DPI
   - Маскировка под реальные популярные сайты
   - Не требует сертификатов
   - Высокая производительность

3. **WebSocket + TLS** - Маскировка под обычный веб-трафик
   - Имитация браузерных заголовков
   - Поддержка ранних данных

4. **gRPC + TLS** - Маскировка под Google сервисы
   - Мультиплексирование
   - Высокая производительность

5. **HTTP/2** - Маскировка под обычный HTTPS трафик
   - Полная имитация браузерных запросов

6. **QUIC** - Современный протокол от Google
   - Низкая задержка
   - Устойчивость к блокировкам

7. **TCP + TLS** - Базовый транспорт с улучшенным TLS fingerprinting

### 🎯 XMUX - Мультиплексирование с мусорным трафиком

**XMUX** - это мощная функция для обхода DPI, которая:
- ✅ Мультиплексирует несколько соединений в одно
- ✅ Генерирует мусорный трафик (40% по умолчанию)
- ✅ Изменяет сигнатуры пакетов в реальном времени
- ✅ Обфусцирует заголовки
- ✅ Поддерживает смешанные типы мусорных данных (HTTP, TLS, DNS, случайные)

**Типы мусорных данных:**
- `random` - Полностью случайные данные
- `http` - HTTP-подобные пакеты
- `tls` - TLS-подобные пакеты
- `dns` - DNS-подобные пакеты
- `mixed` - Смешанные типы (рекомендуется)

### 🔐 Изменение сигнатур пакетов

Система автоматически изменяет сигнатуры пакетов для максимальной маскировки:
- **Randomize** - Случайное изменение байтов
- **Rotate** - Циклический сдвиг
- **Scramble** - Перемешивание байтов
- **Encrypt** - XOR шифрование

Сигнатуры изменяются каждые 3 секунды по умолчанию.

### 🔒 TLS Fingerprinting

Поддержка имитации различных браузеров:
- `chrome` - Google Chrome (рекомендуется)
- `firefox` - Mozilla Firefox
- `safari` - Apple Safari
- `edge` - Microsoft Edge
- `ios` - iOS устройства
- `android` - Android устройства
- `randomized` - Случайный fingerprint

### ⚡ Оптимизированные Policy настройки

- Быстрое рукопожатие (4 секунды)
- Долгие соединения (300 секунд) для избежания переподключений
- Оптимальный размер буфера (4096 байт)
- Улучшенная производительность

## Использование

### Базовая настройка

Добавьте в ваш `.env` файл:

```env
# Включить DPI оптимизации
ENABLE_DPI_OPTIMIZATION=true

# Выбрать предпочитаемый транспорт (по умолчанию: reality)
DPI_PREFERRED_TRANSPORT=reality

# Выбрать TLS fingerprint (по умолчанию: chrome)
DPI_TLS_FINGERPRINT=chrome
```

### Доступные транспорты

```env
# XHTTP (🔥 МАКСИМАЛЬНАЯ ЗАЩИТА - рекомендуется!)
DPI_PREFERRED_TRANSPORT=xhttp

# Reality (очень эффективный)
DPI_PREFERRED_TRANSPORT=reality

# WebSocket
DPI_PREFERRED_TRANSPORT=websocket

# gRPC
DPI_PREFERRED_TRANSPORT=grpc

# HTTP/2
DPI_PREFERRED_TRANSPORT=h2

# QUIC
DPI_PREFERRED_TRANSPORT=quic

# TCP с улучшенным TLS
DPI_PREFERRED_TRANSPORT=tcp
```

### Дополнительные настройки

```env
# Включить мусорный трафик в XMUX (по умолчанию: true)
ENABLE_XMUX_JUNK_TRAFFIC=true

# Включить изменение сигнатур пакетов (по умолчанию: true)
ENABLE_PACKET_SIGNATURE_MUTATION=true
```

## Технические детали

### Как это работает

1. **Генерация конфигурации**: При запуске Xray, система автоматически применяет DPI-оптимизации к конфигурации
2. **TLS Fingerprinting**: Используются правильные TLS параметры для имитации реальных браузеров
3. **Transport оптимизация**: Выбранный транспорт автоматически настраивается с оптимальными параметрами
4. **Policy оптимизация**: Настройки соединений оптимизированы для лучшей производительности и обхода DPI

### Автоматические оптимизации

Система автоматически:
- ✅ Настраивает TLS параметры для выбранного fingerprint
- ✅ Генерирует правильные ALPN протоколы
- ✅ Настраивает заголовки для имитации браузеров
- ✅ Оптимизирует таймауты соединений
- ✅ Настраивает размеры буферов
- ✅ **Генерирует мусорный трафик** для маскировки реального трафика
- ✅ **Изменяет сигнатуры пакетов** в реальном времени
- ✅ **Обфусцирует заголовки** для максимальной маскировки

### Генерация мусорного трафика

Система автоматически генерирует мусорные пакеты для маскировки реального трафика:

**XMUX мусорный трафик:**
- Процент: 40% (настраивается)
- Размер пакетов: 128-2048 байт
- Интервал: каждые 3 секунды
- Типы: смешанные (HTTP, TLS, DNS, случайные)

**XHTTP мусорный трафик:**
- Процент: 30% (настраивается)
- Размер пакетов: 64-1024 байт
- Интервал: каждые 5 секунд
- Типы: HTTP-подобные пакеты

**Типы мусорных данных:**
- `random` - Полностью случайные байты
- `http` - HTTP-подобные заголовки и данные
- `tls` - TLS handshake-подобные пакеты
- `dns` - DNS-подобные пакеты
- `mixed` - Случайная смесь всех типов (рекомендуется)

### Изменение сигнатур пакетов

Система автоматически изменяет сигнатуры пакетов для максимальной маскировки:

**Методы изменения:**
- `randomize` - Случайное изменение отдельных байтов
- `rotate` - Циклический сдвиг байтов
- `scramble` - Перемешивание байтов
- `encrypt` - XOR шифрование с случайным ключом

**Параметры:**
- Интервал изменения: 3 секунды (настраивается)
- Длина сигнатуры: 16-64 байта
- Используются все методы одновременно для максимальной маскировки

## Рекомендации

### Для максимальной защиты от DPI:

1. **Используйте XHTTP транспорт** - максимальная маскировка под обычный HTTP трафик
2. **Включите XMUX с мусорным трафиком** - 40% мусорных пакетов для маскировки
3. **Включите изменение сигнатур пакетов** - сигнатуры меняются каждые 3 секунды
4. Используйте **chrome** fingerprint (самый популярный браузер)
5. Убедитесь, что Xray Core версии 1.8.0 или выше (для Reality и XHTTP)

**Рекомендуемая конфигурация для максимальной защиты:**
```env
ENABLE_DPI_OPTIMIZATION=true
DPI_PREFERRED_TRANSPORT=xhttp
DPI_TLS_FINGERPRINT=chrome
ENABLE_XMUX_JUNK_TRAFFIC=true
ENABLE_PACKET_SIGNATURE_MUTATION=true
```

### Для лучшей производительности:

1. Используйте **gRPC** или **WebSocket**
2. Настройте правильные таймауты
3. Используйте оптимальные размеры буферов

### Для обхода простых DPI:

1. Используйте **WebSocket** или **HTTP/2**
2. Используйте **chrome** или **firefox** fingerprint

## Отладка

Если возникают проблемы:

1. Проверьте логи Xray: `/var/log/supervisor/xray.err.log`
2. Убедитесь, что Xray Core поддерживает выбранный транспорт
3. Проверьте, что все переменные окружения установлены правильно
4. Для Reality убедитесь, что версия Xray >= 1.8.0

## Безопасность

⚠️ **Важно:**
- DPI оптимизации не гарантируют 100% обход всех DPI систем
- Эффективность зависит от конкретной DPI системы
- Всегда используйте актуальные версии Xray Core
- Регулярно обновляйте fingerprint'ы и настройки
